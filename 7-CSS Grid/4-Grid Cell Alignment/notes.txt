          @> ALIGNs GRID ITEMS inside a grid cell along the row axis

                          * justify-items : start;
                          * justify-items : end;
                          * justify-items : center;
                          * justify-items : stretch; -> default

                   }

                        ALIGN ITEMS : (need to have HEIGHT on container]

                @> ALIGN grid items inside a grid cell along the (column axis]                   

                  {
                    * align-item : start;
                    * align-item : end;
                    * align-item : center;
                    * align-item : stretch; -> default
                  } 


[

.grid-container {
  font-size: 40px;
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  justify-items: end; /*even we can use the justify-items and align-items on same container*/
  align-items: center;
  height: 500px;
}


]
