                                  PLACING GRID ITEMS :

              @> GRID ITEMS are auto matically palced in a GRID based on the order they appar in the HTML        

                    # in HTML items moves top to bottom (added img) 
                    # in container -> fills up left to right row            


              @> GRID items can be moved to different cells  


              #@> GRID items can be moved to different cells , by using 

        (grid-row : 1/2 - (STARTING LINE | ENDING LINE)] -> place it on GRID item

        (grid-column : 2/3 - (STARTING LINE | ENDING LINE)] -> place it on GRID item 
         

         {

.grid-item-6 {
  background-color: violet;
  grid-row: 1/2;
  grid-column: 2/3 ;
}

         }

                                 SPANNING GRID CELLS : 

      @> grid-row and grid-column can be used to have grid items span multiple rows or columns 

      (grid-column : 1/4 ; -> (STARTING LINE | ENDING LINE)] -> it occupie from 1 to 4 column

      (grid-row : 1/span 2 ; -> (STARTING LINE | CELLS to SPAN)] -> IT occupie from 1 to 2 from the row  


      {

.grid-item-6 {
  background-color: violet;
  grid-row: 1/2;
  grid-column: 2/3 ;
}

      }

      -|-

      {

.grid-item-5 {
  background-color: blue;
  grid-row: 3/ span 2; /*grid-row: 3/ span 2; OR grid-row: 3/5; */
}


      }

                  ALIGNING GRID ITEMS : (NOT TOO COMMON or not to worry]    

             @> GRID cell ALIGNING can be overridden for individual items                  

      # GRID CONTAINER -> justify-items : center ; | align-items : center ;

      # GRID ITEMS(2) -> justify-self : end ; |  align-self : start ;

               {

                    VALUES : start , end , center , stretch->default

               }     
       


       {

.grid-container {
  font-size: 40px;
  display: grid;
  grid-template-columns: repeat(2, 200px);
  height: 400px;
  justify-items: center;
  align-items: center;
}

.grid-item-5 {
  background-color: blue;
  grid-row: 3/ span 2; /*grid-row: 3/ span 2; OR grid-row: 3/5; */ (actualy it overridden the  justify-items: center; | align-items: center;]
}
       }
