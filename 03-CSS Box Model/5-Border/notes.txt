                  #What is border:
                    *Creats a visible boundary around an HTML element and can enhance visual apperance and separation from other elements...

.......................................................................
                        
                        #Longhand & Shorthand border properties:

                        #=>Longhand border properties:
                          *sets the Individual border properties & applies to all four border(WIDTH,STYLE,COLOR)

              #WIDTH:
                *Border thikness-( border-width : 5px; )
                *DEFAULT-VALUE : Opx
                #VALUES : px - commonly use...

              #STYLE:
                *Border line style - ( border-style : solid; )  
                *DEFAULT-VALUE : none
                #VALUES : [ dotted , dashed , solid , double]

              #COLOR:
                *Border color - ( border-color : red; )
                *DEFAULT-VALUE : element color
                #VALUES : red - { HEX - CODE ]

                ex:

                div {
                      width: 500px;
                      height: 500px;
                      background-color: steelblue;
                      border-width: 5px;
                      border-style: dashed;
                      border-color: rgb(237, 100, 116);
                    }

      #Border design guidance:
        *borders helps with grouping related content(like cards in web-page)
        *Individual border helps separating sections(creating empty border between header and section in web page)
        *borders can create outline buttons which are commonly used along-side solid filled buttons(creating button and gives a modifications-{outline button***])
