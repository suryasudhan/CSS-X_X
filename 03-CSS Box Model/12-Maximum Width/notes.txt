                    #Max width on block & inline elements:

          *Max-width behaves differently depending on the display property of the HTML element... 

                 

::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::::
               
                          #Max width on block element....

        @>Block elements :

                ex: ( h1 , div ) - occupies full width of parent
                    { width & height can be set ]

        @>REGULAR INLINE ELEMENTS :

                ex: ( a , span ) - only occupies width of their content 
                    { width & height can not be set ]-[need to change to use = inline-block so can apply min/max width] 

        @>REPLACED INLINE ELEMENTS :

                ex: ( img , input ) - only occupies width of their content
                    { width & height can be set ]
