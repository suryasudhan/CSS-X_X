                      #WHAT ARE BLOCK AND INLINE ELEMENTS:
      *all HTML elements are by default either a block or inline elements

              =>BLOCK-ELEMENTS:
                *stats on a new line...
                *take up full width of a page...
                  EX: ( h1 , p , ul , li ) - tags*

              =>INLINE-ELEMENTS:
                *does not start on a new line...
                *only occupies width of their content...(unless after a block element)
                  EX: ( a , img , br , input ) - tags*

           #How the box model applies to Block & inline elements:
            

                      #BLOCK ELEMENTS AND THE BOX MODEL:
            *block elements follow the box model rules so applying any properties work as expected...  
                           ex:
                           div{
                                width: 500px;
                                height: 500px;
                                background-color: lightcoral;
                                padding: 50px;
                                border: 10px solid black;
                                margin: 100px;
                              }

                      #INLINE ELEMENTS AND THE BOX MODEL:
            *inline elements do not follow the box model rules so applying some properties do not work as expected...

             { 
               
               *width & height : cannot be set
               *padding : applies but only pushes content away horizontal
               *border : applies but only pushes content away horizontal
               *margin : only applies horizontaly
               
               ]
                           ex:
          .inline-element{
                        background-color: steelblue;
                        width: 200px; it dosen't work on inline-element
                        height: 200px; it dosen't work on inline-element 
                        padding: 100px 100px; it moves little horizontaly
                        border: 20px solid red; 
                        margin: 100px 100px; acting horizontal way only...
                      }

                          #Display property:
                            *Sets how the element is formatted and positioned 

                  [ Display : block; ] - ( property : value )

          VALUES : [ BLOCK , INLINE , INLINE-BLOCK , FLEX , GRID] 
             
                    @=>BLOCK - default value for block element
                    @=>INLINE - default value for block element
