                                     FLEX GROW :

          @> determines how flex-items expand to fill extra space in a container based on a set of PROPERTIES


                      (flex-grow:0;] -> default value | in default behavior is flex-items do not expand , so we calculate how flex-items can fill the extra space                           

          @> items grow based on their flex-grow value relative to the total

                        (
                          box 1 => flex-grow:1; -> gets 1/3 of the remaining space
                          box 2 => flex-grow:2; -> gets 2/3 of the remaining space
                          box 3 => flex-grow:0; -> gets 0/3 of the remaining space
                          box 4 => flex-grow:0; -> gets 0/3 of the remaining space
                          
      TOTAL FLEX-GROW: 1 + 2 + 0 + 0 = (3) , so we using 3* of remaining space to all....
                          ]

                {

          how to add those calculation : 2/3 x 600 -> 2/1 x 300 = 400 + 100(previous box size) => 500
                }          



   {


.flex-container {
  background-color: rgb(236, 156, 182);
  height: 500px;
  width: 1000px;
  display: flex;
}

.flex-item-1 {
  width: 100px;
  height: 100px;
  background-color: blue;
  flex-grow: 1;
  /* 1/3 x 600 -> 200 + 100 = 300  */
}

.flex-item-2 {
  width: 100px;
  height: 100px;
  background-color: blueviolet;
  flex-grow: 2;
  /* 2/3 x 600 -> 2/1 x 300 = 400 + 100(previous box size) = 500*/
}

.flex-item-3 {
  width: 100px;
  height: 100px;
  background-color: red;
  flex-grow: 0;
}

.flex-item-4 {
  width: 100px;
  height: 100px;
  background-color: steelblue;
  flex-grow: 0;
}

   }

   @> items shrink based on their flex-shrink value relative to the total

        @> items shrink based on their flex-shrink value relative to the total

         {

          * BOX 1 = flex-shrink: 2; -> absorbs 0.2 of the overflow space 
          * BOX 2 = flex-shrink: 6; -> absorbs 0.6 of the overflow space  
          * BOX 3 = flex-shrink: 1; -> absorbs 0.1 of the overflow space  
          * BOX 4 = flex-shrink: 1; -> absorbs 0.1 of the overflow space   
   
               (total flex-shrink = 2 + 6 + 1 + 1 => 10] 


          calculation on flex-shrink :  [ BOX 1 = flex-shrink: 2 ] -> 10/2 = 0.2 -> now calculate the overflow of container 1000px to the overflow is 200px -> 0.2 X 200 = 40 , it actualy it's take  box1 - 300px - 40 = 260px-box1

                                      ALIGN SELF :

          @> sets individual flex items alignment by overriding the flex containers default align-items value       

                              (align-self:auto]->DEFAULT value...

                    {
                              *align-self: auto;->DEFAULT value
                              *align-self: stretch;
                              *align-self: flex-start;
                              *align-self: flex-end;
                              *align-self: center;

                             ( *align-items: flex-end;
                              *align-self: baseline; )
                    }                               



[


.flex-container {
  background-color: rgb(236, 156, 182);
  height: 500px;
  width: 1000px;
  display: flex;
