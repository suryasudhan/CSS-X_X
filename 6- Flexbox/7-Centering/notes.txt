              HORIZONTAL CENTERING METHODS : ther are (2 methd to achive content to center]      

               1> BOX MODEL :

      >> margin can be applied left and right to HORIZONTAL center child containers

                    (margin:0 auto;] -> applied on child container only

[
                            .parent-container {
                            background-color: rgb(0, 255, 255);
                            }

                            .child-container {
                            background-color: aquamarine;
                            height: 300px;
                            width: 300px;
                            margin: 0 auto;
                            }

]



               2> FLEXBOX : -> applied on parent container

      >> flex properties make it simple to HORIZONTALly center flex items

                    (
                      justify-content : center ; -> main axis in row
                          align-items : center ; -> main axis in column
                      ]              

           [


                            .parent-container {
                            background-color: rgb(0, 255, 255);
                            display: flex;
                            flex-direction: column;
                            align-items: center; 
                            }

                            .child-container {
                            background-color: aquamarine;
                            height: 300px;
                            width: 300px;
                            }

           ]

                  HORIZONTAL CENTERING CONTENT INSIDE A CONTAINER :

              1> BOX MODEL :

           >> using padding to create internal space left and right gives the illusion that content inside a container is centered...

                    (padding:0 200px;] -> applied on child container   

                    {


                            .parent-container {
                            background-color: rgb(0, 255, 255);
                            }

                            .child-container {
                            background-color: aquamarine;
                            height: 300px;
                            width: 300px;
                            margin: 0 auto;
                            padding: 0 200px;

                            }

                    } 




              2> FLEXBOX :

            >> box model properties still apply on flex items , so padding can still be used to create internal HORIZONTAL space


{

                           .parent-container {
                            background-color: rgb(0, 255, 255);
                            display: flex;
                            flex-direction: column;
                            align-items: center; 
                            }

                            .child-container {
                            background-color: aquamarine;
                            height: 300px;
                            width: 300px;
                            padding:0 200px;
                            }

} 
                    (padding:0 200px;] -> applied on child container

                VERICAL CENTERING CONTENT CONTENT INSIDE a container :(parent container has no set height]  


                1> BOX MODEL :

        >> padding can be applied to the top and bottom of the child container 

           ( padding : 200px 200px;] -> applied on child container...

            {

                            .parent-container {
                            background-color: rgb(0, 255, 255);
                            }

                            .child-container {
                            background-color: aquamarine;
                            height: 300px;
                            width: 300px;
                            margin: 0 auto;
                            padding: 200px 200px;
                            }

            }



                2> FLEXBOX :

        >> parent container has no set height , box model properties still apply on flex items ,so padding can be used to create internal VERICAL space...

                    ( padding : 200px 200px;] -> applied on flex item 


                    {
                            .parent-container {
                            background-color: rgb(0, 255, 255);
                            display: flex;
                            flex-direction: column;
                            align-items: center; 
                            justify-content:center ; 
                            }

                            .child-container {
                            background-color: aquamarine;
                            height: 300px;
                            width: 300px;
                            padding: 200px 200px;
                            }

                    }
