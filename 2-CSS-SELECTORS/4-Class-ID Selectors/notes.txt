                   #the id selectors
                     *selects an element based on a unique id* attribute and can only be used once

                       (we use the id selectors to use - # }
                        
                    ex:both are p-tag but in one using #id

                         p{
                            color: violet;
                          }

                          #red-text{
                            color: blueviolet;
                          }


...............................................................

                     #the class selectors
                      *selects one or more elements based on a class attribute that can be used multiple times

                (we use the class selectors by use - [.]-DOT }


                      ex:

                      p {
                          color: brown;
                          background-color: yellow;
                        }

                        #red-text {
                          color: red;
                          background-color: black;
                        }

                        .blue-text {
                          color: blue;
                          background-color: antiquewhite;
                        }
