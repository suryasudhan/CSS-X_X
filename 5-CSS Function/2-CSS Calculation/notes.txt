                               HOW TO PERFORM CALCULATION :

                @> PERFORM dynamic CALCULATIONs when setting values :
         
            { calc function(mixed units) }={ calc((100%/3) - 50px) }
                   
        
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>
 
                               CALCULATION & VARIABLES :

                @> It is common to use VARIABLES and CALCULATION in combination  


                                    (
                                      :root {
                                              --text-h1: 50px
                                            } 
                                            
                                      h1 {
                                            font-size: calc(var(--text-h1)+10vw);
                                          }      
                                            ]
