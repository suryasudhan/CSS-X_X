                                 WHAT IS BOOTSTRAP

          @> A component-based(CORE PHILOSOPHY] css framework for building-responsive(ALL DEVICES] websites with pre-designed component(BUTTONS , CARDS , NAVBAR ETC...] and utilities(SIMPLE CALSSES]

                             WHY IS BOOTSTRAP HELPFUL

          @> BOOTSTRAP was initially developed in response to major limitations in css layout features ->{developed at twitter}

          # 2017 - flexbox & css grid fully implemented => {layouts were very difficult before 2017]

          # 2018 - utility CALSSES embraced in BOOTSTRAP while retaining component based structure 

          # 2011 - BOOTSTRAP released with grid system & components => {continually improved by making more responsive and adding more components ]
