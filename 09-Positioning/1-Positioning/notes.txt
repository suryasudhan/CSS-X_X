                        FIXED POSITIONING & STICKY POSITIONING  


                                   FIXED POSITIONING


        RECAP -> ABSOLUTE POSITIONING = The element is removed from the normal document flow 

              -> FIXED POSITIONING = Absolute postioning , but the element remains fixed relative to the viewport and is unaffected by acrolling               


{

.container {
  width: 800px;
  height: 1500px;
  position: relative;
  margin-bottom: 100px;
}

.box-3 {
  position: fixed;
  right: 0;
  bottom: 0;
}

}

                               POSITIONING GUIDANCE                              
                        
        @> ABSOLUTE postioning is more commonly used then RELATIVE(slot is removed , so no unexpected gaps in layout] because it removes elements from the document flow -{positioned relative to PARENT container]  

        @> Absolute postioning should be used as a last resort for very sepcific cases as it makes responsive design more challenging - ex: * star added IMG   
 
 
 
        @> FIXED postioning is used for elements that need to be absolute postioned but also need to remain visible when the user scroll - ex: chat box added IMG

        @> sticky postioning is ideal for NAVBARS , As they stay at the top in normal flow and then become fixed when the user scrolls
