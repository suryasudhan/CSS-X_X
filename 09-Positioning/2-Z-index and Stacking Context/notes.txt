                                  STACKING CONTEXT

         @> A positioned element with Z-INDEX creates a new stacking CONTEXT , where its children are stacked independently of other elements    

.........................................................................................

( focus on the Z-INDEX : 1 -> if expanding the element vertical , this element will now act as a container and now going to give it a child element in black | now the Z INDEX of the childis only relative within the parent ....so for example , if i gave this child a much larger Z-INDEX compared to what else is here , like a Z-INDEX of 10 ...>>> take a look on the right to see how this would appear on the webpage of stacked elements<<< | >>>the black element dosen't actually appear above the orange element<<< even thought it has much higher Z-INDEX value ... and that's because any child elements within a container that already has a Z-INDEX value , like the blue container , is only relavent to its parent...... so each of our elements , the red Z-INDEX of 0 , the blue Z-INDEX of 1 and the orange Z-INDEX of 2 , each have their own stacking CONTEXT ... which means that any child elements which have Z-INDEX values are only compared to inside the parent element ... it's kind of like the other elements in the other planes don't exist to the child element.... so even thought our black element,which has a Z-INDEX value of 10-is the highest Z INDEX value across all the planes , the value 10 is only considered within its parent ]
